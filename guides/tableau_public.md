# Guide de réalisation – Tableau Public

1. Ouvrir Tableau Public et connecter le fichier CSV.
2. Vérifier les types de données et les rôles géographiques/date.
3. Créer les feuilles correspondant aux graphiques du storyboard.
4. Définir explicitement les agrégations et les calculs nécessaires.
5. Construire les trois dashboards/onglets.
6. Ajouter les filtres, actions et titres explicites.
7. Vérifier les valeurs sur quelques cas connus et comparer les KPI.
8. Publier sur Tableau Public si les données peuvent être rendues publiques.
9. Copier l'URL et joindre les captures dans le dépôt.

**Confidentialité :** Tableau Public rend les visualisations accessibles publiquement. N'y publier que le dataset d'exercice anonymisé, après vérification, et jamais des données réelles ou confidentielles.
