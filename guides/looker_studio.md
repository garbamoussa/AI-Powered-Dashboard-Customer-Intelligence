# Guide de réalisation – Looker Studio

1. Ouvrir Looker Studio et créer un rapport vierge.
2. Ajouter une source Google Sheets (recommandé pour un TP) ou une source compatible.
3. Vérifier les types de données : dates, nombres, dimensions catégorielles.
4. Créer une page par partie du storyboard.
5. Ajouter les cartes de score pour les KPI validés.
6. Ajouter les graphiques et renseigner dimensions, mesures et agrégations.
7. Ajouter les contrôles de filtre et vérifier leur portée.
8. Harmoniser titres, unités, formats, alignements et couleurs.
9. Tester chaque KPI avec une méthode indépendante.
10. Partager le rapport avec les droits adaptés et copier le lien dans `livrables/lien_dashboard.md`.

**Attention :** la configuration de la source et les options de partage peuvent évoluer. Vérifiez les libellés dans l'interface actuelle. Ne publiez aucune donnée personnelle.
